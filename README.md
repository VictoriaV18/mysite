# 🌐 Django Project: "mysite"

Welcome! This is a simple website built using the [Django](https://www.djangoproject.com/) web framework and deployed to **Heroku**.  
The project was created as part of my self-study journey using the official documentation for Django, Docker, and Heroku.

## 🛠 Tech Stack

- Python 3
- Django
- Docker (for local development)
- Docker Compose
- Heroku (for production deployment)
